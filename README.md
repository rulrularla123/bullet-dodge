## 플레이어 스킬 · 최대 +4 강화

E 관통 레이저, R 회복, T 방어막. 짝수 보스(T2·T4·T6·T8)의 보상에서 새 4번 카드 **스킬 강화**를 선택하면 세 스킬이 함께 1강씩 오릅니다. 기본 +0부터 최대 +4까지이며, 기존 체력/장비/기동성 선택과 별도입니다.

| 강화 | 레이저 총 피해 / 쿨 | 회복량 / 쿨 | 방어막 지속 / 쿨 |
|---|---|---|---|
| 기본 | 600 / 120초 | 1 / 180초 | 4초 / 120초 |
| +1 | 1300 / 120초 | 2 / 180초 | 6초 / 120초 |
| +2 | 1300 / 100초 | 2 / 120초 | 7초 / 120초 |
| +3 | 2700 / 100초 | 3 / 120초 | 10초 / 120초 |
| +4 | 최종 본체 HP의 1/3 (약 4333.33) / 80초 | 3 / 90초 | 10초 / 100초 |

- 레이저 총 피해는 6초간 0.05초마다 총 120회 전부 맞혔을 때의 수치입니다. 적 여러 대를 관통하며 6초간 일반 사격은 중단됩니다. 틱당 피해는 각 단계 총 피해/120입니다.
- 방어막은 유지 시간 동안 피해를 차단하며, 회복은 최대 HP까지만 적용합니다. 최대 HP는 증가하지 않고, 만피에서 사용하면 쿨타임을 소모하지 않습니다.
- 각 스킬은 독립적인 쿨타임을 가집니다. 아이콘의 어두운 덮개와 남은 초는 스킬별 쿨타임에 맞춰 표시합니다. HUD/툴팁에 강화 단계와 현재 효과를 표시합니다.
- 강화 시 진행 중인 쿨타임은 남은 비율을 유지해 새 쿨타임으로 조정합니다. 진행 중인 레이저의 피해와 방어막 지속 시간은 발동 당시 수치를 유지하며, 다음 사용부터 강화 수치가 적용됩니다.
- 체력·장비·기동성·스킬 강화 모두 +4에서는 해당 카드가 보상에서 숨겨집니다. 직접 호출/키보드로도 선택 불가하며 보상 횟수를 낭비하지 않습니다. 모든 항목이 최대면 계속하기 버튼이 표시됩니다.
- E/R/T는 스킬, N은 재시작, 보상창 숫자 1/2/3/4는 체력/장비/기동성/스킬 선택입니다. 보상창에서는 스킬을 사용하지 못합니다.
- 일시정지·보상·게임 종료 중 쿨타임과 유지 시간은 멈춥니다. 재시작하면 강화와 스킬이 초기화됩니다.
- T8 편대 중 보스 무적, T7 발사 전 무적, 최종보스 호위기 무적은 관통 레이저에도 적용됩니다.
- 빠른 확인: `?reward=2`는 보상창, `?skills=4`는 스킬 +4. F2의 ‘스킬 강화’ 버튼으로 디버그 단계를 바꿀 수 있습니다.

## T5~T8 2페이즈 최신 조정

- T5 (HP 30%): 사방 초고속 돌진 5회. 돌진 사이 2초 대기를 제거하고 즉시 다음 경로 예고로 넘어갑니다. 예고 시간 0.8초는 유지합니다.
- T6 (HP 40%): 18초마다 전맵 폭발을 1초 간격 3회 사용합니다. 각 회차는 1.15초 예고 후 폭발하며, 폭발마다 0.3초·최대 7px 진동을 줍니다. 피해 2와 회차별 안전 영역을 유지합니다.
- T7 (HP 10%): 점멸 레이저 충전은 0.175+0.10초로 기존 2페이즈의 절반, 발사 유지는 0.25초, 다음 점멸까지 0.4초입니다. 기체 방향·레이저 방향·회전된 총구를 일치시킵니다. 충전/점멸 중 보스는 무적이며 레이저 발사 중에만 피격됩니다. 레이저 피해 1, 녹색 잔상과 발사 진동을 유지합니다.
- T8 (HP 20%): 레이저 편대를 돌진 편대로 교체했습니다. 기체는 원래 크기(3배)로 표시하고 편대를 7대로 줄였습니다. 매 회차 무작위 1대는 `Tier_08/Enemy_01.png`(체력 68), 나머지 6대는 `Enemy_04.png`(기존 체력 780)입니다. 처음부터 빈 레인은 없으며 약한 기체를 쏴서 제거해야 통로가 열립니다. 0.75초 곡선 진입·0.6초 경로 예고 후 모두 왼쪽으로 1600px/s 돌진하며, 몸체 접촉 피해는 2입니다. 둘 다 무적이 아니고, 살아 있는 1단계도 충돌 피해를 줍니다. 3초 주기 6회와 발진 진동·짧은 섬광을 유지했습니다. 빠른 적과 탄환의 상대 이동을 연속 판정해 낮은 프레임에서도 사격이 누락되지 않게 했습니다.
- 재시작 시 검증용 무적을 OFF로 초기화하고 버튼 표시도 동기화합니다.
- 각성 반복: T5 5연속 돌진과 T8 6회 편대는 종료 후 20초 대기한 뒤 다시 사용합니다. 대기 중 기존 일반 패턴을 사용하며 T5는 진행 중인 일반 돌진을 마친 뒤 각성합니다. T6 3연속 전맵 폭발은 18초 주기로 사용합니다. T7의 점멸 레이저는 기존처럼 처치 전까지 계속 반복합니다.
- T8 편대 진행 중 보스 본체는 무적이며 총알은 편대 기체를 공격할 수 있습니다. 6회 종료 후 보스 피해가 다시 적용됩니다.
- 이 변경은 T5~T8 각성 패턴 업데이트에 포함됩니다.

## 최종보스·회복 규칙 추가 수정

- 본모습 최종보스의 호위기 4개는 일반 탄환 없이 레이저만 발사하고, 오른쪽 전투 영역의 무작위 목표 지점 사이를 독립적으로 움직입니다. 레이저 충전부터 발사 종료까지는 제자리에 고정되며 종료 후 이동을 재개합니다. 호위기 레이저 피해는 1입니다.
- 본체가 위쪽 또는 아래쪽 시작 위치로 이동한 뒤, 사용자 사진의 위·아래 외측 포구와 앞쪽 포구 총 4곳에서 기본 굵기(최대 24px)의 무지개 계열 레이저 4발을 동시에 발사하며 수직 이동합니다. 빅 레이저는 제거했습니다. 각 발의 색은 서로 다르며 공격마다 팔레트를 순환합니다. 빔은 매 프레임 총구에서 화면 왼쪽 끝까지 이어집니다. 외측 포신은 뒤쪽 배기구 대신 왼쪽 포신 끝에서 발사하며 앞쪽 두 포구도 픽셀 중심에 맞췄습니다. 위→아래 이동은 높이 150px~화면 높이 65% 구간으로 제한해 하단 회피 공간을 남깁니다. 아래→위는 본체 하단을 화면 바닥에 맞춘 위치에서 시작하며, 레이저 가장자리와 플레이어 피격 반경을 고려해 상단 1/4을 회피 공간으로 남기고 정지합니다. 소멸 후 원위치로 복귀합니다. 신규 2페이즈는 아직 추가하지 않았습니다.
- 매 보스 격파 시 현재 HP만 1 회복하며 최대 HP는 늘지 않습니다. 회복은 최대 HP까지만 적용되고 중복 처치 콜백으로 반복되지 않습니다.
- 짝수 보스 보상의 체력 강화는 최대 HP만 1 증가시킵니다. 선택 순간 현재 HP는 회복되지 않습니다.
- Tier 5 보스 돌진 옆탄은 이동 방향에 수직으로 양쪽 각 1발씩 0.085초 간격으로 연사합니다. 일반/2페이즈 돌진 모두 적용합니다.
- 본체 평타: 0.78초 간격 탄막과 약 4.5초 간격의 단발 지속 레이저를 혼합합니다. 일반 레이저는 동시에 한 발만 사용하며, 1.2초 충전 후 2.4초 발사합니다. 충전부터 발사 종료까지 초당 0.14rad로 일정하게 훑으며 4포구를 차례로 사용합니다.
- 이동 레이저: 일반 공격 약 10초 뒤 별도로 사용하며 위→아래 / 아래→위를 번갈아 사용합니다. 5번 보스처럼 빗금·점선 없는 반투명 붉은 위험 구역과 실선 경계로 1.1초 범위·방향 경고, 3단계 충전, 발사 순간 섬광과 최대 7px 진동, 유지 중 2.2px 진동을 적용했습니다. 이동 방향에 따라 하단 또는 상단 1/4 회피 공간을 남기고 총구 끝 발사 좌표를 유지합니다. 에너지 오라와 픽셀 입자를 추가했으며 체력 UI는 흔들리지 않습니다.
- 검증 시나리오는 총 70개입니다. `F2 → 최종 무지개 4레이저`로 새 본체 패턴을 바로 확인할 수 있습니다.

## 조작법 (Controls)

- **이동**: `WASD` 또는 `방향키 (↑ ↓ ← →)`
- **정밀 이동 (저속 모드)**: `Shift` 유지
- **공격**: 자동 발사 (짝수 보스 격파 보상으로 장비 강화 선택 시 `Lv0 → Lv4`까지 단계별 진화)
- **보상 카드 선택 (2·4·6·8보스 격파 시)**: 마우스 클릭 또는 숫자키 `1` (체력 강화), `2` (장비 강화), `3` (기동성 강화)
- **일시정지 / 재개**: `ESC` 또는 `P`
- **즉시 재시작**: `N`
- **검증용 디버그 패널 열기/닫기**: `F2` 또는 우측 상단 `디버그 (F2)` 버튼

## V3 주요 변경 및 구현 사항

1. **레이저 높이 다변화·스윕 및 순간이동(위치 점프) 현상 완전 제거**
   - 보스가 레이저를 발사할 때 화면 정중앙(`Y = 362`)에서만 수평 발사하지 않고, 오른쪽 1/3 영역(`X >= 856`) 안에서 이중 주파수 위상 적분(`boss.phaseX`, `boss.phaseY`)으로 상단·중상단·중앙·중하단·하단 전 구간을 부드럽게 이동하며 **현재 위치한 총구에서 즉시 발사**합니다.
   - `Stage_01` 예고부터 `Stage_03` 발사까지 일정한 각속도로 회전하는 **스윕 레이저(Sweeping Laser)** 및 사전 예고 사선 레이저가 추가되었습니다.
   - 레이저 시작·종료 시 속도 계수(`boss.moveSpeedFactor`)를 선형 보간하고 위상(`phaseX`, `phaseY`)을 누적 적분하여, 기존 `sin(age * scale)` 방식에서 발생하던 위치 점프(순간이동)를 원천 차단했습니다.

2. **후반부 체력 스케일링 대폭 강화 (적 & 보스 HP 테이블)**
   - **일반 적 체력**: `HP = 2 * Math.ceil(34 * Math.pow(1.25, tier - 1) * [1.0, 1.35, 1.8, 2.4][enemyIdx - 1])` (`Tier_01 Enemy_01 = 68` → `Tier_08 Enemy_04 = 780`).
   - **보스 체력 (`BOSS_HP_TABLE`)**: `Tier_01: 600`, `Tier_02: 900`, `Tier_03: 1300`, `Tier_04: 1900` (호위기 각 `240`), `Tier_05: 2700`, `Tier_06: 3800`, `Tier_07: 5200`, `Tier_08: 7000`, `Final_Shadow: 6500`, `Final_Revealed: 13000`.

3. **본모습 최종보스(`Final_Boss_Revealed`) 강화 — 4기 호위기 레이저 + 본체·호위기 동반 저속 전진 돌진**
   - 4기의 무적 독립 호위기(`Final_Minion_01..04.png`)가 일반 탄막 외에 주기적으로 각자의 기수 총구에서 3단계 레이저(`Lime`, `Cyan`, `Yellow`, `Pink`)를 발사합니다(최대 2기 동시 레이저 제한).
   - 본모습 최종보스 본체가 예고(`WARN`, `0.95s`) 후 수평 정면(`vy = 0`)으로 플레이어 진영(`X = 340`)까지 **느리게 전진 돌진(`RUSH`, `260 px/s`)**했다가 복귀(`RETURN`, `290 px/s`)합니다.
   - **오른쪽 1/3 예외 규칙 확대**: 본모습 최종보스가 전진 돌진(`RUSH`) 및 복귀(`RETURN`)하는 동안에는 **본체와 4기의 호위기 모두** 오른쪽 1/3 경계(`X >= 856`) 제한에서 예외 처리되어 편대 대형을 유지한 채 플레이어 진영 깊숙이 함께 압박하며, 복귀 완료 시 다시 `X >= 856` 제한이 활성화됩니다.

4. **6보스(`Tier_06`) — 플레이어 주변 포위 고속 4연발 시한폭탄 미사일**
   - 일반 탄환 없이(`0발`), 매 공격마다 4개의 날개 미사일 포트(`muzzles[0..3]`)에서 **4발의 고속 미사일(`700 px/s`)**을 `0.065s` 간격으로 연속 발사합니다.
   - 발사 시점 플레이어 위치를 둘러싸는 4개의 포위 좌표(`(-78, -74), (-78, +74), (+84, -74), (+84, +74)`)로 날아가 도착 후 `0.28초` 뒤 폭발하며 **2 데미지**를 입힙니다.

5. **7보스(`Tier_07`) 레이저 두께 정확히 2배 확대 (`16px / 32px / 48px`)**
   - `Tier_07` 보스 레이저에만 `widthMultiplier = 2`를 적용하여 렌더 두께와 `Stage_03` 충돌 판정 지름을 모두 기존 `8 / 16 / 24px`의 정확히 **2배(`16 / 32 / 48px`, 반지름 `24px`)**로 확대했습니다(`Origin`/`Tip` 비율 왜곡 없음).

6. **5보스(`Tier_05`) 돌진 — 완전 수평 정면 직선 돌진 (`vy = 0`)**
   - 예고(`WARN`) 단계에서 돌진 높이(`dashY`)로 정렬한 뒤, 돌진(`DASH`) 중에는 `dashVy = 0`, `boss.y = boss.dashY`를 엄격히 유지하여 예고선과 100% 일치하는 수평 직선으로만 돌진합니다.

7. **8보스(`Tier_08`) 돌진 기체 속도 2~3배 상향 (`1340 ~ 1540 px/s`) 및 스폰 물량 대폭 확대**
   - `Tier_08/Enemy_04.png` 돌진 기체 속도를 기존 `560 px/s`에서 **`1340 ~ 1540 px/s` (약 `2.57배`)**로 대폭 상향했습니다.
   - 스폰 주기를 `0.75 ~ 0.97초`로 단축하고 평행 오프셋 레인으로 한 번에 `1 ~ 3기`씩 버스트 스폰하며(최대 동시 `6기`), 연속 선분 스윕 충돌 판정(`distSqPointToSegment`)으로 30fps/60fps 모두에서 터널링 없이 정확히 판정합니다.
# 신규 전기 스테이지 시안 (T8)

진행 순서는 T7 → 전기 T8 → 기존 레이저/돌진편대 T9 → 그림자/최종보스입니다. T8 전기 보스 처치 시 네 번째 강화 보상을 줍니다. 기존 패턴과 에셋 ID를 보존하기 위해 내부 패턴 ID 9는 전기, 8은 기존 레이저/돌진 보스이며, `STAGE_ORDER`가 실제 순서와 화면 표시를 정합니다. URL `tier`는 화면에 표시되는 스테이지 번호입니다. 원본 전기 기체는 `assets/enemies/Tier_09/`에 저장되어 있습니다.

전기 보스는 0.65초 후 첫 구체를 발사하고 나머지를 0.7초 간격으로 발사합니다. 중앙 발사구는 항상 처음 또는 마지막이며 뒤쪽 두 발사구의 순서는 랜덤입니다. 각 구체는 자기 발사 시각 직전 0.5초 동안만 별도로 충전합니다. 발사구 좌표는 원본 이미지의 끝부분에 맞췄습니다. 구체마다 속력을 215~285px/초에서 매번 독립적으로 뽑고 발사 이후에는 보스와 분리됩니다. 1발이면 구체만, 2발이면 연결선, 3발이면 마지막 변까지 닫힌 삼각형 전류를 만듭니다. 각 변과 구체는 피해 1, 이동 스턴 0.3초를 줍니다. 공격 주기 3.2초, HP 9500은 시안값입니다.

보스는 삼각형 공격 두 번 이후 5갈래 전기 레이저로 전환합니다. 2.65초 충전 후 5초간 발사하며 초당 최대 0.035rad(약 2도)만 추적합니다. 전방 총구 3곳과 양끝 노란 구체 2곳에서 각각 한 발씩 총 5발을 쏩니다. 레이저 간 각도는 0.26rad(약 15도), 전체 부채꼴은 약 60도로 벌어집니다. 위쪽 총구는 위쪽으로, 아래쪽 총구는 아래쪽으로 퍼져 발사구 앞에서 교차하지 않습니다. 기존 잡몹 3단계와 같은 전기 애니메이션을 사용합니다. 충전 중에는 보스가 평소의 30% 속도로 움직이고, 발사 중에는 멈춥니다. 충전 중 5개 레이저의 실제 발사 경로를 붉은 반투명 띠로 화면 끝까지 표시하며, 예고선은 총구와 조준 방향을 따라 움직이고 피해가 없습니다. 삼각형 구체는 정리하고 새로 만들지 않습니다. 발사 순간 0.2초 청록색 섬광과 강한 짧은 진동, 유지 중 약한 진동이 들어갑니다. 피해 1 및 스턴 0.3초입니다. 끝나면 1.5초 후 삼각형 패턴으로 돌아가 반복합니다.

보스 2페이즈는 HP 50%(4750/9500)에서 시작합니다. 전방 3개 총구에서 구체 15개를 날립니다. 8개는 네 모서리와 각 변의 중앙에 고르게 고정 배치하고, 7개는 맵 중앙 영역에 랜덤 배치합니다. 구체 자체에는 접촉/비행 피해가 없습니다. 배치가 끝난 후 1.4초간 실제 연결 경로를 예고하고, 6초간 전류가 흐릅니다. 각 구체의 연결 수는 최대 5개입니다. 전체 노드를 잇는 기본 연결을 먼저 만든 뒤 제한 내에서 추가 연결을 생성하여, 고립된 구체 없이 하나의 전류망을 유지합니다. 모든 전류 구간에 피격 판정을 적용합니다. 전류는 피해 1과 스턴 0.3초를 줍니다. 패턴 중 삼각형/5갈래 레이저는 중단하며, 종료 후 일반 패턴으로 돌아가고 20초 후 전류망을 반복합니다. 보스 피격은 유지됩니다.

체력 60%(5700/9500)부터 이동 규칙 전기선이 추가됩니다. 0.75초 예고 후 화면 앞/뒤(오른쪽/왼쪽) 중 랜덤한 쪽에서 위아래 끝을 잇는 수직 전기선이 700~800px/초로 반대편까지 지나갑니다. 선은 기울어지지 않으며 파랑과 빨강은 서로 독립적인 타이머로 나옵니다. 파란색은 실제 이동 중일 때만, 빨간색은 실제 정지 중일 때만 피해 1을 줍니다. 각 색상의 쿨타임은 각각 6~8초이고, 체력 60% 도달 시점부터 각자의 첫 쿨타임을 계산합니다. 한 색상의 발사는 다른 색상 쿨타임을 초기화하지 않습니다. 쿨타임이 동시에 끝나더라도 한 번에 하나만 발사하며, 전기선 출현 사이에는 공통 3~4초 대기 간격을 둡니다. 대기 중 다른 색상의 쿨타임은 계속 흐르고, 준비가 먼저 끝난 색상부터 차례로 발사합니다. 등장 순간 색상에 맞는 0.2초 섬광과 강한 짧은 진동, 통과 중 약한 진동을 줍니다. 50% 전류망 및 일반 보스 패턴과 함께 동작합니다. 키 입력만이 아니라 프레임 사이 실제 변위로 판정하므로 벽에 막히거나 스턴에 걸려 못 움직이면 정지로 취급합니다. 일시정지/보스 처치/재시작 시 함께 멈추거나 정리됩니다.

청색·적색 투명 PNG 스프라이트 시트는 `assets/effects/Electric_Laser/Electric_Laser_Blue_Spritesheet.png`와 `Electric_Laser_Red_Spritesheet.png`에 저장되어 있습니다. 기존 전기 시트를 내장 image_gen으로 색상 변경한 결과이며 각각 7프레임입니다. 제작 프롬프트도 같은 폴더의 `Generation_Prompt_Blue.txt`와 `Generation_Prompt_Red.txt`에 보관했습니다.

잡몹 1~2단계는 구체만 발사합니다. 3단계는 실제 두 발사구에서 동시에 2.65초간 길게 충전한 뒤 0.85초간 전기 레이저를 쏩니다. 충전은 총구에서만 표시되며 레이저가 보이는 첫 순간부터 피해를 줍니다. 플레이어 방향으로 초당 최대 0.20rad(약 11.5도)씩 천천히 조준합니다. 4단계는 실제 두 발사구에서 0.6초 간격으로 별도로 충전/발사한 두 구체를 전류 한 줄로 연결합니다. 속력은 각각 190~255px/초입니다.

잡몹·보스의 모든 전기 공격은 피해 1과 이동 스턴 0.3초를 줍니다. 피격 시 기체 주변에 0.3초간 전기 스파크와 감전 표시가 나오며, 파랑/빨강 전기선은 해당 색상으로 표시됩니다. 스턴은 실제 피해가 들어온 경우에만 적용되고 피격 무적/방어막 중에는 갱신되지 않습니다. 자동사격은 유지됩니다. 전류의 그림과 피격 판정은 같은 구체 좌표를 사용합니다. 일시정지/리셋/보스 처치 시 전기 패턴도 함께 정지/정리됩니다.
